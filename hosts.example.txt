# 每行一台主機：代號  SSH 登入目標  [其他 ssh 參數]

#   SSH 登入目標：帳號@IP（建議寫 IP；主機名稱要這台電腦查得到才能用）
#   其他 ssh 參數：例如 SSH 不是 22 埠時加 -p 2222
# 「#」開頭的行是註解。報告上只會出現代號，這份清單請留在自己的單位。
