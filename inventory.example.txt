# 主機清單範本
# 最簡單的做法：輸入 ./hc 開啟選單，選「2. 用 SSH 檢查多台主機」，照畫面輸入，選單會幫你建好 inventory.txt。
# 想自己編輯的話，複製成 inventory.txt 再修改：
#   cp inventory.example.txt inventory.txt
#
# 每行一台主機：代號  帳號@IP  [其他 ssh 參數]
#   代號：報告上顯示的名稱，只能用英文字母、數字與 . _ -，每台要不同
#   帳號@IP：SSH 登入用的帳號與主機 IP（建議寫 IP；主機名稱要這台電腦查得到才能用）
#   其他 ssh 參數：例如 SSH 不是 22 埠時加 -p 2222
# 「#」開頭的行是註解。報告上只會出現代號，這份清單請留在自己的單位。

H01   admin@10.0.0.5
H02   ops@10.0.0.6     -p 2222
